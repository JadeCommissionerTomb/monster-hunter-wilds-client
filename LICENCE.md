## 🧩 About

**Monster Hunter Wilds Client** is a comprehensive client for Monster Hunter Wilds featuring overlay, trainer options, auto-farm, and Lua scripting.

Based on popular mods like **MHW Trainer**, **Wilds Overlay**, and **Script Hub**.

## ✨ Features

### 🎮 Core Client
- Overlay — in-game menu with hotkey toggle
- Trainer — infinite health, stamina, and items
- Auto-Farm — automate monster hunting and resource gathering
- Speedhack — adjust game speed
- Teleport — fast travel to any location

### 🎨 Cosmetics & Unlocks
- Unlock All — access all armor, weapons, and decorations
- Custom Skins — apply any cosmetic without restrictions
- Visual Effects — toggle effects for better visibility

### 🏋️ Scripting & Automation
- Lua Scripting — write custom scripts for automation
- Script Hub — load pre-made scripts
- Macro Recorder — record and replay actions
- Auto-Craft — automatically craft items
- Auto-Upgrade — upgrade gear without manual input
